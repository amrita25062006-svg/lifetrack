# 🩺 LifeTrack

### AI-Powered Health & Wellness Tracking Platform

LifeTrack is a full-stack health and wellness web application designed to help users monitor their health information, track wellness-related data, and access useful insights through a simple and user-friendly interface.

## 🌐 Live Demo

**Live Application:** https://lifetrack-nu.vercel.app/

## ✨ Features

* 📊 **Health Dashboard** — View important health information in one place.
* 👤 **Personal Health Profile** — Manage and organize personal health details.
* 📈 **Health Tracking** — Monitor health and wellness information over time.
* 🤖 **AI-Powered Insights** — Generate useful insights from available health data.
* 🔔 **Health Notifications** — Stay informed about important updates.
* 💻 **Responsive Interface** — Designed to work across different screen sizes.
* 🔗 **Full-Stack Architecture** — Separate frontend and backend for better scalability and maintainability.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/amrita25062006-svg/lifetrack.git
cd lifetrack
```

### 2. Set Up the Backend

```bash
cd backend
```

Install the required dependencies according to the backend configuration:

```bash
pip install -r requirements.txt
```

Start the backend server:

```bash
python manage.py runserver
```

> If your backend uses a different startup command, use the command specified by your backend configuration.

### 3. Set Up the Frontend

Open another terminal:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application should then be available locally through the frontend development server.
